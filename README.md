Escolhemos desenvolver um sistema de estoque para uma loja de roupas jeans, com base nas necessidades de uma empresa real.

Nesse sistema, é possível:

- Cadastrar, remover, atualizar e deletar (CRUD) clientes, funcionários e peças de roupa no estoque;
- Realizar e registrar vendas, com gerenciamento do valor em estoque;
- Criar relatório de vendas do mês;

Para implementá-lo, usamos algumas noções aprendidas na disciplina de Programação 2:

- [Diagrama de classes](https://miro.com/app/board/uXjVI3HmXOc=/?moveToWidget=3458764651691973245&cot=14)
- Operações CRUD
- Funções e tipos de retorno diferentes
- Classes, objetos, métodos, atributos
- Herança e polimorfismo
- Classes abstratas e interface
- Modificadores de acesso
- Sobrecarga de método
- Construtores
- Validação de input e tratamento de exceções
- Uso da biblioteca GSON para leitura/escrita em arquivo .json (persistência dos dados)
- Manipulação de strings
- Array, ArrayList, Enum, constantes e variáveis usando static e final
